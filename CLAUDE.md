## Project

Arcade Vault is an online platform for playing games and competing for the highest scores. The project is at the freshly-scaffolded stage (Create Next App); the app code under `app/` is still the default template.

Development follows **Spec Driven Design** using the `/spec` and `/spec-impl` skills from [Klerith/fernando-skills](https://github.com/Klerith/fernando-skills) (install with `npx skills@latest add Klerith/fernando-skills`). Write a spec before implementing features.

## Stack and conventions

- **Next.js 16.3 (App Router only, `app/` directory)** with React 19.2. APIs differ from older Next.js — consult `node_modules/next/dist/docs/` (`01-app/`, `03-architecture/`, `index.md`) before writing Next-specific code.
- Route prop types use the global generated helpers (e.g. `LayoutProps<"/">`, `PageProps<...>`) rather than hand-written prop interfaces; these come from `.next/types` generated by `next dev`/`next build`.
- **Tailwind CSS v4** via `@tailwindcss/postcss` — there is no `tailwind.config.*`. Theme tokens are declared in CSS with `@theme inline` in `app/globals.css` (colors map to `--background`/`--foreground` CSS variables, fonts to Geist via `next/font`).
- TypeScript strict mode; import alias `@/*` maps to the repo root.
